# TT Money (หน้าแอพ)

ไฟล์ในโฟลเดอร์นี้คือหน้าแอพทั้งหมด อัปโหลดขึ้น GitHub Pages (ฟรี) แล้วเปิดจากมือถือ

- `index.html`, `style.css`, `app.js`  หน้าแอพ
- `manifest.webmanifest`, `sw.js`, `icons/`  ทำให้ติดตั้งเป็นแอพบน Android และเปิดได้ตอนไม่มีเน็ต

ไม่มีความลับอยู่ในไฟล์เหล่านี้ (URL กับ token เก็บไว้ในมือถือของ TT เท่านั้น) จึงอัปโหลดเป็น repo สาธารณะได้

เวลาแก้โค้ดแล้วอัปโหลดใหม่: เปลี่ยน `ttm-v1` ใน `sw.js` เป็นเลขถัดไป (เช่น `ttm-v2`) มือถือจะได้โหลดเวอร์ชันใหม่
