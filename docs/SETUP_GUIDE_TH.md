# คู่มือติดตั้ง TT Money (ฉบับให้ AI ช่วยสอน)

> **วิธีใช้ไฟล์นี้**
> 1. ดาวน์โหลดไฟล์นี้ (หรือก๊อปข้อความทั้งหมด)
> 2. เปิด AI ที่ถนัด เช่น ChatGPT, Claude หรือ Gemini แล้วอัปโหลดไฟล์นี้เข้าไป
> 3. พิมพ์ว่า **"ช่วยสอนฉันติดตั้ง TT Money ตามคู่มือนี้ทีละขั้น"**
>
> ใช้เวลาประมาณ 20-30 นาที ไม่ต้องเขียนโค้ดเป็น แค่ก๊อปวางและกดตามที่ AI บอก

---

## ส่วนที่ 1: สำหรับ AI ที่ช่วยสอน (อ่านก่อนเริ่มสอน)

คุณคือติวเตอร์ที่ช่วยผู้ใช้ติดตั้ง TT Money ซึ่งเป็นแอพจดรายรับรายจ่ายส่วนตัว ผู้ใช้อาจไม่เคยเขียนโค้ดและไม่เคยใช้ Apps Script

**วิธีสอน**
- สอน**ทีละขั้น** ขั้นละ 1-3 การกระทำ แล้วถามว่าทำเสร็จหรือยัง และเห็นอะไรบนจอ ก่อนไปขั้นต่อไป
- บอกชื่อปุ่มหรือเมนูให้ตรงกับที่เห็นบนจอ หน้าจอ Google อาจเป็นภาษาไทยหรืออังกฤษ ให้บอกทั้งสองแบบ เช่น "ส่วนขยาย (Extensions)"
- ถ้าผู้ใช้เจอ error ให้ขอให้พิมพ์ข้อความ error มา แล้วดูตารางในส่วนที่ 5 ก่อน
- ให้ทำตามโครงสร้างในส่วนที่ 3 **แบบเป๊ะ ๆ** ทั้งชื่อแท็บ ตำแหน่งเซลล์ และหัวคอลัมน์ เพราะโค้ดอ่านข้อมูลจากตำแหน่งเหล่านี้ตรง ๆ ถ้าย้ายแถวหรือคอลัมน์ แอพจะอ่านผิด
- อย่าแก้โค้ดใน `Code.gs` นอกจากผู้ใช้ขอเอง และเข้าใจว่าจะต้องดูแลโค้ดต่อเอง

**กฎความปลอดภัย (สำคัญมาก)**
- **ห้ามขอให้ผู้ใช้พิมพ์หรือวาง token ในแชท** และห้ามขอภาพหน้าจอที่เห็น token ถ้าผู้ใช้เผลอวางมา ให้เตือนว่าควรรัน `resetToken()` เพื่อสร้าง token ใหม่
- ไม่ต้องขอ Web app URL หรือลิงก์ Google Sheet ของผู้ใช้ ทุกอย่างทำได้โดยไม่ต้องเห็นค่าเหล่านี้
- token คือรหัสผ่านเข้าข้อมูลการเงินของผู้ใช้ ใครมี token + URL จะอ่าน แก้ และลบข้อมูลได้ทั้งหมด

**หลังติดตั้งเสร็จ** ถ้าผู้ใช้อยากปรับต่อ ช่วยได้ เช่น เพิ่มหมวด ทำปุ่มจดเร็ว ทำกราฟในแท็บใหม่ หรือสอนสูตร Google Sheets แต่ห้ามเปลี่ยนโครงสร้างในส่วนที่ 3

## ส่วนที่ 2: ภาพรวม (อ่านเพื่อเข้าใจ)

```
แอพในมือถือ  ──(ส่งคำสั่ง + token)──>  Apps Script  ──>  Google Sheet ของคุณ
(หน้าตา/ปุ่ม)                          (ตัวกลาง ตรวจ token)     (เก็บข้อมูล)
```

- **ข้อมูลอยู่ใน Google Drive ของคุณเอง** เจ้าของแอพหรือคนอื่นมองไม่เห็น เพราะแต่ละคนมี Sheet และ Apps Script แยกของตัวเอง
- หน้าแอพใช้ลิงก์เดียวกันทุกคน แต่ละคนใส่ URL และ token ของตัวเองตอนตั้งค่า ค่านี้เก็บอยู่แค่ในมือถือของคุณ
- ฟรีทั้งหมด ใช้แค่บัญชี Google

**สิ่งที่ต้องมี:** บัญชี Google, คอมพิวเตอร์ (ทำบนคอมง่ายกว่ามาก เพราะหน้า Apps Script ใช้บนมือถือลำบาก), มือถือที่จะใช้แอพ

## ส่วนที่ 3: โครงสร้าง Google Sheet (ต้องตรงทุกตำแหน่ง)

สร้าง Google Sheet ใหม่ 1 ไฟล์ ตั้งชื่ออะไรก็ได้ เช่น `TT Money` แล้วสร้าง **4 แท็บ** ชื่อตามนี้เป๊ะ ๆ (ตัวพิมพ์เล็ก-ใหญ่ต้องตรง):

`Transactions`, `Wallets`, `Categories`, `Presets`

### 3.1 แท็บ `Transactions` (รายการทั้งหมด)
แถว 1 คือหัวคอลัมน์ ใส่ตามนี้ (A1 ถึง M1) ตั้งแต่แถว 2 ลงไปปล่อยว่าง แอพจะเขียนให้เอง

| A | B | C | D | E | F | G | H | I | J | K | L | M |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| ID | DateTime | Type | Category | SubCategory | Amount | MyShare | Wallet | ToWallet | Note | RentForMonth | Source | Deleted |

ความหมาย (ไว้อ่านเข้าใจ ไม่ต้องกรอก):
- `Type` คือ `Income` (รับ), `Expense` (จ่าย) หรือ `Transfer` (โอนระหว่างกระเป๋า)
- `MyShare` คือส่วนที่เป็นของเราจริง ๆ ตอนหารกับเพื่อน
- `Deleted` คือ `N` ปกติ, `Y` ถูกลบ (ลบแบบซ่อน กู้คืนได้)

### 3.2 แท็บ `Wallets` (กระเป๋าเงิน)
| เซลล์ | ใส่อะไร |
|---|---|
| A2 | ข้อความ `วันเริ่มใช้` |
| **B2** | **วันที่เริ่มใช้แอพ** เช่น `1/12/2026` (ให้เป็นวันที่จริง ไม่ใช่ข้อความ) |
| A4 ถึง G4 | หัวคอลัมน์: `Name`, `Type`, `Opening`, `Balance`, `Counted`, `Difference`, `Note` |
| แถว 5 ถึง 14 | กระเป๋าได้สูงสุด 10 ใบ (1 แถวต่อ 1 ใบ) |

ในแต่ละแถวของกระเป๋า:
- **A (Name):** ชื่อกระเป๋า เช่น `เงินสด`, `KBank`, `TrueMoney`, `เงินเก็บ` (ถ้ามีกระเป๋าชื่อ `เงินสด` แอพจะเลือกให้เป็นค่าเริ่มต้น)
- **B (Type):** อย่างใดอย่างหนึ่งต่อไปนี้ `Cash`, `Bank`, `E-wallet`, `Savings`, `Other` (กระเป๋าที่เป็น `Savings` จะถูกนับเป็นเงินเก็บ ไม่เอามาคิดเป็นงบใช้รายวัน)
- **C (Opening):** ยอดเงินจริงในกระเป๋านั้น ณ เช้าวันที่ใส่ใน B2
- **D (Balance):** สูตร (ด้านล่าง) ห้ามพิมพ์ตัวเลขเอง
- **E (Counted):** ปล่อยว่าง แอพจะใส่ให้ตอนกด "เทียบยอด"
- **F (Difference):** สูตร (ด้านล่าง)
- **G (Note):** จดอะไรก็ได้

**สูตรใน D5** (วางที่ D5 แล้วลากลงถึง D14):
```
=IF($A5="","",$C5
 +SUMIFS(Transactions!$F:$F,Transactions!$C:$C,"Income",Transactions!$H:$H,$A5,Transactions!$M:$M,"<>Y",Transactions!$B:$B,">="&N($B$2))
 -SUMIFS(Transactions!$F:$F,Transactions!$C:$C,"Expense",Transactions!$H:$H,$A5,Transactions!$M:$M,"<>Y",Transactions!$B:$B,">="&N($B$2))
 -SUMIFS(Transactions!$F:$F,Transactions!$C:$C,"Transfer",Transactions!$H:$H,$A5,Transactions!$M:$M,"<>Y",Transactions!$B:$B,">="&N($B$2))
 +SUMIFS(Transactions!$F:$F,Transactions!$C:$C,"Transfer",Transactions!$I:$I,$A5,Transactions!$M:$M,"<>Y",Transactions!$B:$B,">="&N($B$2)))
```
ความหมาย: ยอดตั้งต้น + รายรับ − รายจ่าย − โอนออก + โอนเข้า นับเฉพาะรายการที่ไม่ได้ถูกลบ และเกิดตั้งแต่วันเริ่มใช้ (รายจ่ายนับเต็มจำนวน `Amount` เพราะเงินออกจากกระเป๋าเต็มจำนวน แม้จะหารกับเพื่อน)

**สูตรใน F5** (วางที่ F5 แล้วลากลงถึง F14):
```
=IF(OR($A5="",$E5=""),"",$E5-$D5)
```
ความหมาย: ยอดจริงที่นับได้ − ยอดตามระบบ ถ้าติดลบแปลว่าเงินจริงน้อยกว่าที่จด (อาจลืมจดรายจ่าย)

### 3.3 แท็บ `Categories` (หมวด)
แถว 1: `Type`, `Category`, `Count` (A1, B1, C1)
ตั้งแต่แถว 2 ใส่หมวดที่ใช้บ่อย **เรียงจากใช้บ่อยสุดไว้บน** (แอพจะโชว์ 7 อันแรกเป็นปุ่มใหญ่) ตัวอย่าง:

| Type | Category |
|---|---|
| Expense | อาหาร |
| Expense | กาแฟ |
| Expense | เดินทาง |
| Expense | ของใช้ |
| Expense | Subscriptions |
| Expense | ค่าห้องรายเดือน |
| Income | เงินเดือน |
| Income | รายได้เสริม |
| Transfer | โอนย้าย |

คอลัมน์ C ปล่อยว่างได้ ถ้าจดหมวดใหม่ในแอพ ระบบจะเพิ่มแถวให้เอง พร้อมสูตรนับจำนวนครั้งที่ใช้
(หมวดชื่อ `ค่าห้องรายเดือน` เป็นหมวดพิเศษ แอพจะถามเพิ่มว่าเป็นค่าห้องของเดือนไหน)

### 3.4 แท็บ `Presets` (ปุ่มจดเร็ว)
แถว 1: `Label`, `Type`, `Category`, `SubCategory`, `Amount`, `Wallet` (A1 ถึง F1)
ตั้งแต่แถว 2 ใส่ของที่ซื้อซ้ำบ่อย ๆ ตัวอย่าง:

| Label | Type | Category | SubCategory | Amount | Wallet |
|---|---|---|---|---|---|
| กาแฟ | Expense | กาแฟ | | 55 | |
| ข้าวเที่ยง | Expense | อาหาร | | 60 | เงินสด |

`Category` ต้องมีอยู่ในแท็บ Categories, `Wallet` ปล่อยว่างได้ หรือใส่ชื่อกระเป๋าให้ตรงกับแท็บ Wallets, `Amount` ปล่อยว่างได้ถ้าราคาไม่แน่นอน

## ส่วนที่ 4: ขั้นตอนติดตั้ง

**ขั้นที่ 1: สร้าง Sheet**
สร้างตามส่วนที่ 3 ให้ครบทั้ง 4 แท็บ

**ขั้นที่ 2: เปิด Apps Script**
ใน Google Sheet กดเมนู **ส่วนขยาย (Extensions) → Apps Script** จะเปิดแท็บใหม่ที่มีไฟล์ `Code.gs` (โค้ดว่าง ๆ)

**ขั้นที่ 3: วางโค้ด**
1. เปิดลิงก์โค้ด: https://raw.githubusercontent.com/TT-Trying/tt-money/main/backend/Code.gs
2. เลือกทั้งหมด (Ctrl+A) แล้วก๊อป
3. กลับไปหน้า Apps Script ลบโค้ดเดิมใน `Code.gs` ทิ้งให้หมด แล้ววางโค้ดใหม่
4. กดไอคอนบันทึก 💾

**ขั้นที่ 4: ตั้งเขตเวลา**
แถบซ้ายกด ⚙️ **การตั้งค่าโปรเจกต์ (Project Settings)** → Time zone เลือก **(GMT+07:00) Bangkok** (ถ้าไม่ตั้ง เวลาที่จดจะเพี้ยน)

**ขั้นที่ 5: รัน setup**
1. กลับไปที่ไฟล์ `Code.gs` ด้านบนจะมีช่องเลือกฟังก์ชัน ให้เลือก **`setup`** แล้วกด **▶ เรียกใช้ (Run)**
2. ครั้งแรกจะขึ้นให้ขอสิทธิ์ กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี Google ของตัวเอง
3. ถ้าขึ้นว่า **"Google hasn't verified this app"** เป็นเรื่องปกติ เพราะเป็นสคริปต์ที่เราสร้างเอง กด **ขั้นสูง (Advanced)** → **ไปที่ ... (ไม่ปลอดภัย) / Go to ... (unsafe)** → **อนุญาต (Allow)**
4. ด้านล่างจะมี **Execution log** แสดงข้อความ `TOKEN ของคุณ (คัดลอกเก็บไว้): ...`
5. **คัดลอก token เก็บไว้ในที่ปลอดภัย** เช่น โน้ตส่วนตัวในมือถือ **ห้ามส่งให้ใคร และห้ามวางในแชท AI**

(ถ้าอยากเช็คว่าอ่าน Sheet ได้ถูก ให้เลือกฟังก์ชัน `selfTest` แล้วกด Run จะเห็นรายชื่อกระเป๋าใน log)

**ขั้นที่ 6: Deploy เป็น Web app**
1. มุมขวาบนกด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอน ⚙️ ข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
4. กด **Deploy** แล้วคัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`

> "ทุกคน (Anyone)" แปลว่าใครก็ส่งคำขอมาที่ URL นี้ได้ แต่ถ้าไม่มี token ที่ถูกต้อง ระบบจะปฏิเสธทุกคำขอ ข้อมูลจึงยังปลอดภัย ตราบใดที่ token ไม่หลุด

**ขั้นที่ 7: เชื่อมแอพ**
1. เปิดลิงก์แอพในมือถือ: **[ลิงก์แอพ TT Money จากเจ้าของแอพ]**
2. ใส่ **Web app URL** (จากขั้นที่ 6) และ **Token** (จากขั้นที่ 5) แล้วกด **เชื่อมต่อ**
3. ติดตั้งเป็นแอพบนหน้าจอ: ใน Chrome กดเมนู ⋮ → **เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป** (iPhone: ใน Safari กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**)

**ขั้นที่ 8: ตั้งยอดเริ่มต้น**
ในแอพ ไปที่แท็บ **กระเป๋า** แล้วใส่ยอดตั้งต้นของแต่ละกระเป๋าให้ตรงกับเงินจริง ณ วันเริ่มใช้ เสร็จแล้วกลับไปหน้าภาพรวม ลองกด **+ จด** ดูได้เลย 🎉

## ส่วนที่ 5: แก้ปัญหาที่เจอบ่อย

| ข้อความ / อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| `Token ไม่ถูกต้อง` | token ที่ใส่ในแอพไม่ตรง | ก๊อป token ใหม่ให้ครบทุกตัว ไม่มีช่องว่างหัวท้าย ถ้าลืม token ให้รัน `showToken()` แล้วดูใน log |
| `อ่านคำตอบไม่ได้ ตรวจว่า URL ลงท้ายด้วย /exec และ Deploy แบบ Anyone` | ใช้ URL ผิด หรือตั้งสิทธิ์ไม่ใช่ Anyone | ใช้ URL ที่ลงท้าย `/exec` (ไม่ใช่ `/dev` และไม่ใช่ลิงก์หน้าแก้โค้ด) และเช็คว่าตั้ง Who has access เป็น Anyone |
| `ยังไม่ได้รัน setup()` | ข้ามขั้นที่ 5 | รัน `setup` |
| `ไม่พบแท็บ ...` | ชื่อแท็บไม่ตรง | แก้ชื่อแท็บให้ตรงส่วนที่ 3 เป๊ะ ๆ (ไม่มีช่องว่าง) |
| `ไม่พบกระเป๋า: ...` | ชื่อกระเป๋าในปุ่มจดเร็วหรือรายการ ไม่ตรงกับแท็บ Wallets | แก้ชื่อให้ตรงกัน |
| `ช่องกระเป๋าเต็ม (สูงสุด 10)` | แถว 5-14 เต็มแล้ว | ลบกระเป๋าที่ไม่ใช้ในแท็บ Wallets |
| ยอดกระเป๋าเป็น 0 หรือไม่เปลี่ยน | สูตรใน D5:D14 ไม่ครบ หรือ B2 ไม่ใช่วันที่ | ใส่สูตรตามส่วนที่ 3.2 และเช็คว่า B2 เป็นวันที่จริง |
| เวลาที่จดเพี้ยนไปหลายชั่วโมง | ไม่ได้ตั้งเขตเวลา | ทำขั้นที่ 4 แล้วกด Deploy ใหม่ตามส่วนที่ 6 |
| แก้โค้ดแล้วแอพยังทำแบบเดิม | ยังไม่ได้ Deploy เวอร์ชันใหม่ | ดูส่วนที่ 6 |

## ส่วนที่ 6: อัปเดตโค้ดในอนาคต

เมื่อเจ้าของแอพแจ้งว่ามีโค้ดเวอร์ชันใหม่:
1. ก๊อปโค้ดใหม่จากลิงก์ในขั้นที่ 3 ไปวางทับใน `Code.gs` แล้วบันทึก
2. **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments)** → กดไอคอน ✏️ แก้ไข
3. ช่อง Version เลือก **เวอร์ชันใหม่ (New version)** → กด **Deploy**

**อย่ากด "New deployment"** เพราะจะได้ URL ใหม่ แล้วต้องไปกรอกในแอพใหม่ทั้งหมด

## ส่วนที่ 7: ความปลอดภัยของคุณ

- **token = กุญแจเข้าข้อมูลการเงินของคุณ** ห้ามส่งให้ใคร ห้ามวางในแชท AI ห้ามแคปหน้าจอที่เห็น token
- ถ้าสงสัยว่า token หลุด: เลือกฟังก์ชัน **`resetToken`** แล้วกด Run จะได้ token ใหม่ (token เก่าใช้ไม่ได้ทันที) จากนั้นใส่ token ใหม่ในแอพ
- อย่าแชร์ Google Sheet ให้คนอื่นแก้ไขได้ ถ้าจะให้ดูให้แชร์แบบ "ผู้มีสิทธิ์อ่าน"
- ข้อมูลที่ "ลบ" ในแอพจะถูกซ่อน (คอลัมน์ `Deleted` = `Y`) แต่ยังอยู่ใน Sheet ถ้าอยากลบถาวรให้ลบแถวนั้นใน Sheet เอง
- สำรองข้อมูล: Google Sheet มีประวัติเวอร์ชันอยู่แล้ว (**ไฟล์ → ประวัติเวอร์ชัน**) หรือจะดาวน์โหลดเป็น .xlsx เก็บไว้เดือนละครั้งก็ได้
